DHT22 IoT Monitoring System

Temperature - Humidity Monitoring and Fan Alarm Control

About System

This project is an IoT environmental monitoring system using ESP32 and DHT22 sensor.

The system collects temperature and humidity data, controls cooling fan automatically and activates warning alarm when abnormal conditions occur.
